# Set up a printable mystery session with a free complete case

Start with The Empty Envelope, the complete free printable case linked below. It lets you inspect the format before deciding whether the optional Quiet Evidence collection suits your group.

Choose one person to manage the hints and solution pages. Keep those pages separate from the evidence while the group works. Read the setup first, then compare the clues and write a provisional explanation. When participants disagree, ask which clue supports each explanation.

Use progressive hints when the group stalls. Reveal one at a time and pause to reconsider the evidence before opening the next. At the end, compare the proposed answer with the explanation and discuss any assumption that caused a different interpretation.

The paid collection contains three English A4 investigations, a separate hint-and-solution booklet and a start guide. It can be read on screen or printed. The free case is separate from the three paid cases. Duration, difficulty and suitability for a particular group should be assessed using the free sample.

Both printable products are pilot editions created with generative AI assistance. Independent human playtesting is pending. Feedback about unclear clues is welcome through the store's contact route.
