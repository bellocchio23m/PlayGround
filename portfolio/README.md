# Marco Bellocchio — practical tools and original demonstrations

## Review JSON translations before handoff

[LocaleCheck](https://bellocchio2.gumroad.com/l/localecheck-json) is an offline JSON translation checker with an EN/IT HTML workspace and an optional Python CLI. The downloadable kit is listed at EUR29 once. Start with the [free format-fit guide](resources/json-format-fit.md), [release checklist](resources/json-release-checklist.md) and [fictional interface demo](localization/README.md).

## Repair a blocked web workflow

Inspect the original [MVP Rescue before/after demonstration](mvp-rescue/README.md). Use the [written bug brief](resources/bug-report-brief.md) and [acceptance worksheet](resources/acceptance-criteria.md) to describe a real problem. [Request scope and pricing through Contra](https://contra.com/s/N3gqmcUE-mvp-rescue-fix-a-broken-form-or-dashboard-workflow). Final scope, compensation, deadline and acceptance criteria are agreed before work.

## Try a deduction case

[Paper Alibi](https://bellocchio23m.itch.io/paper-alibi) contains 24 free browser cases with EN/IT/ES text and progressive hints. There is also a [complete free printable case](https://payhip.com/b/751yB) and an optional [three-case PDF collection](https://payhip.com/b/BCYwv). These are AI-assisted pilot editions with independent human playtesting pending.
