Send work for review

Export unapproved strings. The reviewer opens the package in this same HTML application, edits it and returns a response file. No account is required.

Receive completed work

Compare the original package, the response and the current project. Conflicts require an explicit choice. Returned translations always require your approval.

Release checks

Previous delivery / baseline

Run checks to inspect structural errors, terminology warnings and review status.

A release requires every current source string to be approved and no structural errors. Terminology warnings remain visible for human review. Draft catalogs can be saved from the editor.
